# LAMC - Lycée des Arts et Métiers

LAMC Website - Original als Schlussprojekt für den HTSTA Cours aus dem 1. Jahrgang.\
Projekt wird nun recycled als Schlussprojekt für den COSER Cours im 2. Jahrgang, in Kombination mit einem Linux Server.\
Die Idee ist, den Linux Server als Sharepoint zu verwendet, um es zu ermöglichen manche Dateien herunterladen zu können.

Das Projekt wird über GitHub und Discord gemanaged.
